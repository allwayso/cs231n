本笔记通过线性规划 **对偶理论（Duality Theory** 的视角，用直观的“博弈谈判”类比，来推导并证明经典指派问题（如学生匹配工作）中 **匈牙利算法（Hungarian Algorithm)** 的数学正确性与收敛性。

## 一、 核心舞台：原问题与对偶问题

指派问题的核心目标，是把 $n$ 个学生分配给 $n$ 份工作，让**总代价（如总耗时或总花费）最小**。

### 1. 原问题（Primal Problem）：现实的分配

设 $c_{ij}$ 为学生 $i$ 选择工作 $j$ 的实际代价。我们引入决策变量 $x_{ij}$，如果学生 $i$ 匹配工作 $j$，则 $x_{ij} = 1$，否则 $x_{ij} = 0$。

$$\min \sum_{i=1}^n \sum_{j=1}^n c_{ij} x_{ij}$$

$$\text{s.t. } \quad \sum_{j=1}^n x_{ij} = 1 \quad (\forall i), \quad \sum_{i=1}^n x_{ij} = 1 \quad (\forall j), \quad x_{ij} \in \{0, 1\}$$

### 2. 对偶问题（Dual Problem）：期望的谈判

为了理解算法的底层逻辑，我们引入一种**虚拟的记账与谈判机制**，为买卖双方设置心理预期：

- 为每一个学生 $i$ 设置一个变量 $u_i$，代表学生的“期望底薪”。
    
- 为每一份工作 $j$ 设置一个变量 $v_j$，代表老板的“期望补贴”。
    

对偶问题的数学模型为：

$$\max \sum_{i=1}^n u_i + \sum_{j=1}^n v_j$$

$$\text{s.t. } \quad u_i + v_j \le c_{ij} \quad (\forall i, j)$$

> **谈判的基本规则（对偶约束）**：在任何时候，学生开出的底薪 $u_i$ 加上工作开出的补贴 $v_j$，**绝对不能超过**这门工作的实际代价 $c_{ij}$。如果超过了，说明双方预期过高，这笔买卖在现实中根本无法成立。而我们的目标，是在不破坏规则的前提下，让所有人的**总期望（目标函数）尽可能地大**。

## 二、 支撑算法的两大对偶定理

为什么我们可以通过操控“虚拟期望”来解决“现实分配”？运筹学提供了两个强力的数学定理：

### 1. 弱对偶性：天花板与地板的关系

**结论**：任何一组满足谈判规则的期望总和 $\sum u_i + \sum v_j$，必然**小于或等于**任何一种现实中可行匹配的总代价。

**证明**：假设我们找到了一个现实中的完美匹配方案。因为对所有组合都有 $u_i + v_j \le c_{ij}$，我们把所有真正匹配上的对子（即 $x_{ij}=1$ 的项）两边求和：

$$\sum_{\text{matched } (i,j)} (u_i + v_j) \le \sum_{\text{matched } (i,j)} c_{ij} = \text{现实当前总代价}$$

因为是完美匹配，每个人和每份工作刚好出场一次，所以左边求和的结果刚好等于所有人的总期望 $\sum u_i + \sum v_j$。

这证明了：**虚拟的总期望，永远是现实总代价无法逾越的下限（下界）。**

### 2. 强对偶性与互补松弛条件：黄金平衡点

**结论**：当且仅当满足以下条件时，两边同时达到最优解：

$$\text{若现实中学生 } i \text{ 和工作 } j \text{ 匹配了 } (x_{ij} = 1) \implies u_i + v_j = c_{ij}$$

**直观解释**：我们在算法中对矩阵进行变换，定义改造成本 $c'_{ij} = c_{ij} - u_i - v_j$。当 $u_i + v_j = c_{ij}$ 时，矩阵对应的位置就会变成 **$0$**。

这意味着，**只要我们能利用矩阵里的 $0$ 元素凑出一个让每个人都有份的完美匹配，这个匹配就绝对是最优解**。因为此时“期望总和”刚好顶到了“现实代价”的下限，两边相等。

## 三、 匈牙利算法矩阵操作的对偶实质

我们在纸上进行的矩阵减法和划线操作，本质上是一场**暗中调整对偶变量（期望值）的谈判过程**。

### 1. 行减与列减：赋予初始谈判资本

- **操作**：每行减去该行最小值；每列减去该列最小值。
    
- **对偶实质**：在等式 $c'_{ij} = c_{ij} - u_i - v_j \ge 0$ 中，某一行减去一个常数，等加于**让这个学生的期望底薪 $u_i$ 增加了这么多**。因为减去的是最小值，矩阵元素始终 $\ge 0$（未违反谈判规则）。
    
- **结果**：每一行/列出现的 $0$，代表由于期望调整，该组合的买卖谈成了（$u_i + v_j = c_{ij}$），具备了匹配可能。
    

### 2. 划线覆盖与矩阵调整：针对僵局的博弈

当现有的 $0$ 没办法让每个人都分到一个时（无法完美匹配），我们要用最少的直线（行线或列线）把所有的 $0$ 覆盖住。此时，没被划线覆盖的格子里，**最小的数字是 $\Delta$**。

算法在这一步对矩阵的加减，翻译成谈判语言极其精妙：

- **对于没被划线的行（学生）**：说明这些学生目前一个能谈成的工作都没有。算法的处理是：**让他们把期望底薪 $u_i$ 提高 $\Delta$**。
    
- **对于被划线的列（工作）**：说明这些工作太热门了，有很多学生抢着要。算法的处理是：**让这些工作的期望补贴 $v_j$ 降低 $\Delta$**。
    

我们来看看两边一加一减后，矩阵中不同区域的化学反应：

| **矩阵区域分类**  | **矩阵元素 cij′​ 的变化** | **对应对偶变量的变化**                                                                                                    | **谈判博弈分析**                                                                         |
| ----------- | ------------------ | ---------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| **未被任何线覆盖** | 减去 $\Delta$        | $u_i \leftarrow u_i + \Delta$<br><br>$v_j$ 不变                                                                    | 学生提薪，工作补贴没变。总期望变大，距离实际代价更近了，**催生出新的 $0$（新机会）**。由于原值 $\ge \Delta$，减完仍 $\ge 0$，符合规则。 |
| **单线覆盖区域**  | 保持不变               | **情况A**：行未划线且列划线 $\implies u_i$ 增 $\Delta$, $v_j$ 减 $\Delta$<br><br>**情况B**：行划线且列未划线 $\implies u_i$ 不变, $v_j$ 不变 | 一增一减互相抵消，或者均保持不变。**总期望和矩阵数字都不变**，原本谈成稳固的 $0$ 依然是 $0$。                              |
| **双线交叉点**   | 加上 $\Delta$        | $u_i$ 不变<br><br>$v_j \leftarrow v_j - \Delta$                                                                    | 热门工作的补贴降低了，而抢它的学生没变。总期望变小，在矩阵中表现为**代价加上 $\Delta$**（原本的 $0$ 变成正数，暂时放弃它）。            |

## 四、 核心证明：为什么算法绝不会死循环？

要证明算法一定会收敛并结束，必须证明**每经过一次调整，整个系统的总期望值都在严格变大**。

根据图论中的 **König-Egerváry 定理**（最大匹配数 = 最小点覆盖数）：

因为当前现有的 $0$ 无法形成完美匹配，所以用来覆盖所有 $0$ 的**最少总线数（行线数 $R$ + 列线数 $C$）必然严格小于总人数 $n$**。

我们来计算整个系统进行一次 Step 4 调整后，对偶目标函数（总期望）的总净改变两：

- 所有没划线的行（共 $n - R$ 行），其 $u_i$ 统统**增加了 $\Delta$**。
    
- 所有划了线的列（共 $C$ 列），其 $v_j$ 统统**减小了 $\Delta$**。
    

$$\text{总期望净变量} = (n - R) \cdot \Delta - C \cdot \Delta = \left[n - (R + C)\right] \cdot \Delta$$

因为：

1. 最少覆盖线数满足 $R + C < n \implies n - (R + C) > 0$（提薪的学生比降补的工作多）
    
2. $\Delta$ 是未覆盖区域的最小值，显然 $\Delta > 0$
    

因此：

$$\text{总期望净变量} > 0$$

### 最终结论

1. **方向正确**：每一次调整矩阵，系统的总期望之和都**严格严格增大**，现实代价的下限被不断抬高。
    
2. **必然终止**：由于现实中的最低总代价是一个固定有限的数，下限不可能无限制地抬高，因此算法不可能陷入死循环，必然在有限步内终止。
    
3. **全局最优**：当总期望无法再增大时，意味着线数达到了 $n$，通过 $0$ 元素刚好能连出一条覆盖每个人的完美匹配。此时强对偶定理闭环，该方案必为全局最优解。
