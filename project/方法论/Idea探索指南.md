## 一、四维交叉Idea生成法

### 维度1：从已掌握知识出发（最优先）

- 核心技能池（CS231N覆盖）：图像分类与迁移学习、目标检测、语义分割、GAN/Diffusion基础、自监督学习基础、模型可解释性
- 生成方法：将每个技能与实际问题关联，避免涉足未学过的复杂方向（如3D视觉、NeRF）

### 维度2：从有趣/有用的小问题出发（最易出亮点）

- 核心逻辑：解决自己真正关心的小问题，而非为做项目而做项目
- 生成方法：
  1. 记录一周内遇到的可被CV解决的痛点
  2. 从个人兴趣爱好延伸
  3. 聚焦"小众但高频"的特定场景问题

### 维度3：从数据集出发（你的思路，优化版）

- 优化原则：
  1. 优先选择有预训练模型、标注质量高、有明确评估指标的数据集
  2. 尝试跨领域应用，将一个领域的数据集用于解决另一类问题
- 推荐平台：Papers with Code Datasets、Hugging Face Datasets、Kaggle Datasets、CS231N官方推荐数据集

### 维度4：从方法改进出发（适合深入研究）

- 适合课程项目的轻量改进方向：
  1. 效率改进：模型轻量化、推理加速
  2. 鲁棒性改进：抗噪声、遮挡、光照变化
  3. 数据效率改进：小样本、半监督学习
  4. 可解释性改进：决策过程可视化
  5. 方法组合：融合不同方法解决新问题

## 二、项目选择黄金评估标准

| 评估维度     | 好项目特征               | 坏项目特征                |
| -------- | ------------------- | -------------------- |
| **可行性**  | 数据易获取，单卡GPU可训练，时间充足 | 需自行标注大量数据，需多卡训练，时间不足 |
| **创新性**  | 有自己的小改进或新应用场景       | 完全复现他人论文，无任何个人贡献     |
| **展示性**  | 有直观可视化结果，易于展示       | 仅有数字指标，成果难以直观呈现      |
| **学习价值** | 能运用CS231N知识，同时学到新技能 | 仅调用API，无技术含量         |
| **应用价值** | 能解决实际问题，有潜在用途       | 纯学术研究，无实际应用场景        |
