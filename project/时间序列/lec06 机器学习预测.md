## 一、 核心概念：时间预测的三要素

在设计多步预测模型前，必须明确以下三个时间点/段：

- **预测源头（Forecast Origin）**：做出预测的时间点（即能获取到训练数据的最后一个时间点 $t$）。
    
- **预测时界/预测期（Forecast Horizon）**：需要预测的未来时间段（如未来 1~8 周）。
    
- **提前期/延迟（Lead Time / Latency）**：从“预测源头”到“预测时界开始”之间的时间差。由于数据收集通常有延迟，我们往往需要提前做出预测（例如：在第 $t$ 周，预测第 $t+2$ 周到第 $t+9$ 周的数据，此时提前期为 2）。
    

## 二、 数据结构转化（监督学习表格化）

传统机器学习不能直接处理单维时间序列的多步预测，必须将数据转化为“单行对应单次预测任务”的表格结构：

- **特征（Features, X）**：利用历史数据的滞后项（Lags）。若存在提前期（Lead Time），则滞后项需整体向后平移。
    
- **目标（Targets, Y）**：多步预测的目标是一个**多列矩阵**。每一行都必须包含整个预测期内的所有未来时间点（如 `y_step_1`, `y_step_2`, ..., `y_step_n`）。
    

## 三、 四种多步预测策略

| **策略名称**                         | **实现原理**                                                   | **优缺点**                                                      |
| -------------------------------- | ---------------------------------------------------------- | ------------------------------------------------------------ |
| **1. 多输出模型**<br>                 | 使用原生支持多因变量输出的算法（如线性回归、神经网络），一次性输出所有步。                      | **优**：简单、计算速度快。<br><br>**缺**：受限于算法，许多主流 ML 模型（如 XGBoost）不支持。 |
| **2. 直接策略**<br>_(Direct)_        | 为预测期内的每一步**分别训练一个独立的模型**（如模型 1 预测第 1 步，模型 2 预测第 2 步）。      | **优**：能针对每一步独立建模，准确度较好。<br><br>**缺**：预测步数多时，训练和维护模型的计算成本极高。  |
| **3. 递归策略**<br><br>_(Recursive)_ | 只训练一个单步预测模型。先预测未来第 1 步，然后**将该预测值作为特征**喂给模型，继续预测第 2 步，以此类推。 | **优**：只需训练一个模型，计算量小。<br><br>**缺**：误差会随着步数推进不断累积（单步错，步步错）。    |
| **4. DirRec 策略**                 | 为每一步训练独立模型（直接策略），但在预测下一步时，会将前面所有步的**预测值作为新特征**加入输入（递归策略）。  | **优**：能捕捉序列的时间相关性。<br><br>**缺**：计算量巨大，且同样受到递归误差累积的影响。        |
> 关于各种多步预测策略的讨论可以参考[[bontempiMachineLearningStrategies2013c]]
> 
## 四、 代码实现要点（以 Python 为例）

### 1. 构建多步目标矩阵

通过负向平移（`shift(-i)`）将未来的真实值拉到当前行，形成多列目标：

Python

```
# 构建未来 steps 步的目标矩阵
def make_multistep_target(ts, steps):
    return pd.concat({f'y_step_{i + 1}': ts.shift(-i) for i in range(steps)}, axis=1)
```

### 2. 传统 ML 模型的直接策略改造

由于 XGBoost 等算法原生不支持多输出，在应用**直接策略**时，需使用 `sklearn` 的包装器进行化整为零的处理：

Python

```
from sklearn.multioutput import MultiOutputRegressor
from xgboost import XGBRegressor

# 核心：用 MultiOutputRegressor 包装 XGBoost
# 后台会自动为每一个预测步（如 y_step_1 到 y_step_8）分别建立并训练一个独立的 XGB 树模型
model = MultiOutputRegressor(XGBRegressor())
model.fit(X_train, y_train)  # y_train 为多列矩阵
```

> 📌 **核心结论**：多步预测的本质不是改变算法本身，而是通过**数据重构（多列目标）**或**模型架构（多模型组合/包装器）**，将多步预测问题降维转化为机器学习可解决的监督学习问题。
