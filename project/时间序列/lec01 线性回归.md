## 时间序列的基本特征

时间序列有两个基本特征，时间步（time step）特征和滞后（lag）特征

## 时间步特征

将表示较为复杂的时间序列归一化到从0开始的相对时间序列上，实际上就是建立了一个相对时间特征t

|            | NumVehicles | Time |
| ---------- | ----------- | ---- |
| Day        |             |      |
| 2003-11-01 | 103536      | 0    |
| 2003-11-02 | 92051       | 1    |
| 2003-11-03 | 100795      | 2    |
| 2003-11-04 | 102352      | 3    |
| 2003-11-05 | 106569      | 4    |
## 滞后特征

其实我觉得不如叫作“提前特征”，即将所有时间向前平移若干单位，作为一个特征列。实际上建立了前后事件之间的特征
